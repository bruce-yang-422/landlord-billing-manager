為台灣房東設計的輕量帳務工具，解決多戶共用一個台電電號時的電費分攤問題：依累進費率計算各戶電費、依人數分攤水費，並一鍵產出可傳給租客的 LINE 報表。

資料只存在你的瀏覽器，不需註冊帳號，也沒有後端伺服器。

## 功能特色

- **台電累進電費分攤**：共用電號（5F + 6F）只需輸入一次帳單，支援夏月／非夏月費率；5F 不需獨立電表。
- **彈性抄表**：6F 可依實際日期抄表，結算時自動配對最接近台電計費區間的讀數。
- **水費分攤**：依各戶居住人數比例計算，人數設定會長期保留。
- **多戶獨立帳單**：各戶分開設定租金、收款帳戶與備註，並可分別輸入瓦斯費、管理費與其他費用。
- **LINE 報表**：一鍵複製含分攤說明的報表；房東私用備註不會出現在報表中。
- **水電費儲值**：可逐戶啟用，並逐項選擇要抵扣的費用；租金不提供抵扣。
- **歷史資料**：提供卡片與表格兩種檢視，可依樓層篩選並查看計算明細。
- **CSV 備份還原**：中文欄名的 UTF-8 CSV，附逐列內容驗證值，並相容舊版備份。
- **PWA**：可安裝至手機與桌面，首次載入後可離線使用。
- **主題**：支援亮色、暗色與自動切換。

## 使用指南

### 1. 首次設定

1. 開啟「設定」，分別填入 5F、6F 的租金、居住人數與收款資訊。
2. 在「備註」分頁填入固定備註（提供給租客）與房東備註（僅供記錄）。
3. 點「💾 儲存房客設定」，自動返回計算帳單頁。

收款欄位需自行填寫，沒有自動查詢對照。銀行代號與帳號以文字保存，會保留開頭的 0。

| 欄位 | 範例 |
| --- | --- |
| 銀行名稱 | 第一銀行 |
| 分行名稱 | 台北分行 |
| 銀行代號 | 007 |
| 戶名 | 王小明 |
| 帳號 | 001234567890 |

有填寫帳號時，LINE 報表才會列出收款資訊；未填的銀行名稱、分行名稱或代號不會顯示空白標籤。

### 2. 導覽

介面依「資料輸入、計算帳單、歷史資料、房客儲值、設定」排序，每次顯示一個畫面，並支援瀏覽器上一頁。手機版使用底部導覽，桌面版使用側欄。切換畫面不會丟棄設定頁尚未儲存的內容，但要按「儲存房客設定」才會正式存檔。

### 3. 6F 抄表

1. 開啟「資料輸入」，選擇抄表日期並輸入電表累計讀數。上期讀數會依日期自動取最近一筆較早的紀錄。
2. 檢查本次用電量後，點「儲存本次抄表」。這一步不需要台電帳單。
3. 沒有歷史資料時，先補登一筆起始日期與讀數。

抄表規則：

- 間隔不需固定，也可在資料輸入頁編輯或刪除獨立抄表紀錄。
- 舊 6F 帳單的**本期**讀數也會作為歷史來源；同日期優先使用獨立抄表資料。
- 可以儲存零用電；補登或修改的讀數必須介於前後紀錄之間。

### 4. 每月費用

在「資料輸入」填寫水費總額，以及各戶的瓦斯費、管理費與其他費用。

- 水費須填寫上次及本次水表抄表日，依兩次抄表相隔天數計算；入住日期及居住人數在「設定」儲存，入住日未填則視為整期入住。
- 每戶水費＝水費總額 × 人數 × 入住天數 ÷（總人數 × 帳期天數），入住前費用由房東負擔，預覽分別顯示兩戶及房東金額。個別取整後調整尾差，確保加總等於帳單且房東負擔不為負。
- 例如 8/1～10/1 相隔 61 天、總額 424 元：5F 5 人於 8/26 入住（36 天），分攤 209 元；6F 1 人於 8/2 入住（60 天），分攤 70 元；房東負擔 145 元。
- 輸入值會自動記憶；按「儲存費用」可驗證水費期間與費用並取得儲存成功或失敗回饋，再前往計算帳單。正式存檔帳單時才會抵扣儲值；未收取的項目填 0。
- 水費可取消勾選「本期收取水費」：原水費與分攤明細仍保留顯示，帳單、歷史及圖片標示「本期不收」，由房東吸收，不計入應收總額或儲值抵扣。開關會記憶，每張帳單保存當時選擇並隨 CSV 備份；舊帳單未記錄此選擇時仍視為正常收取。
- 其他費用可選填內容（例如「更換門鎖」），內容按樓層記憶。每張帳單保存當時的內容，後續修改輸入不影響歷史帳單。

到「計算帳單」可逐項查看租金、水費、瓦斯、電費與應收總額。沒有台電帳單的月份，取消勾選「本次收取台電電費」即可存檔一般月帳單；此選擇會被記憶，台電結算月請重新勾選。

### 5. 台電雙月結算

1. 開啟「計算帳單」，確認帳單日期；季節會依台電帳期自動判斷，無須手動選擇。
2. 輸入台電帳單金額與總度數。
3. 填寫台電帳單的用電起訖日期（獨立於帳單日期，含迄日）。系統以起日及「迄日翌日」為計費邊界，配對附近最近的抄表紀錄，同距離取較早日期。
   - 搜尋範圍預設前後 7 天，可設為 0～31 天（0 表示只採用與計費邊界同日的紀錄），設定會記憶在此瀏覽器。
   - 可手動改選範圍內的紀錄，或按「重新自動配對」。
4. 核對各戶應收總額並儲存，接著會前往「歷史資料」，可在此複製 LINE 報表。

租客提早或延後拍照時，以所選兩筆抄表的平均每日用電，線性推算計費邊界的讀數：

```text
日均用電 = (實際結束讀數 − 實際起始讀數) ÷ 實際抄表相隔天數
帳單天數 = 台電迄日翌日 − 台電起日
邊界讀數 = 實際起始讀數 + 日均用電 × (計費邊界日期 − 實際起始日期)
6F 用電 = 日均用電 × 帳單天數
5F 用電 = 台電總度數 − 6F 用電
```

例如 2026/9/4 讀數 11378.4、11/10 為 11763.2，67 天用電 384.8 度；台電帳期 9/3～11/3 含末日共 62 天，對齊 9/3 與 11/4 的讀數後，6F 估計用電為 **356.08 度**。這期跨夏月 28 天、非夏月 34 天，按台電總額 3064 元及總度數 1097 度分攤，6F 為 **916 元**，5F 為 **2148 元**。

跨季計算依 2026 年 11 月 3064 元帳單的公式：6/1～9/30 採夏月，其餘日期採非夏月，計入帳期起訖日；跨年及閏年也按實際日數計算。對每戶同一筆用電度數，分別套用兩個月的夏月與非夏月累進級距，再依天數加權（不拆分度數後重新套級距）：

```text
單戶理論電費 = 夏月累進電費 × 夏月天數 / 帳期天數
             + 非夏月累進電費 × 非夏月天數 / 帳期天數
差額 = 台電帳單總額 − 5F 理論電費 − 6F 理論電費
單戶分攤 = 單戶理論電費 + 差額 × 單戶度數 / 台電總度數
```

5F 分攤四捨五入至元，6F 取帳單總額減去 5F，確保兩戶加總等於帳單。季節天數與公式會保存於當期備註；CSV 季節欄支援「跨季」，仍可匯入舊的單季帳單。

計算保留完整精度，畫面度數顯示至小數兩位。估算假設每日平均用電相同，實際用電可能不同；搜尋範圍內缺少紀錄、抄表區間與帳期不重疊或讀數無效時會阻止存檔，需先補登或改選。實際拍照日期與讀數保留不變，估算公式及對齊讀數自動寫入當期備註，並隨 CSV 匯出；已存檔帳單不會自動重算。相鄰帳期以同一邊界交接，不重複計入末日。

### 6. 備註

自動產生的電費估算、跨季費率及水費分攤採分段條列，度數顯示至小數兩位，內部計算保留完整精度。入住日期、水費抄表期間及分攤說明隨 CSV 備份保存，舊備份仍可匯入。

6F 的拍照日期、電表累計讀數與回推公式僅提供於 6F 帳單。5F 帳單只列出 6F 本期使用度數供核對分攤，不顯示其抄表與估算細節；舊帳單的自動估算段落在產生 5F 租客圖文報表時也會隱藏。

帳單 PNG 固定為 A4 直式比例，解析度 **2480 × 3508 像素**（約 300 DPI 的 A4 尺寸）。依內容重新換行及調整字級，避免裁切或將圖片拉長；內容超過一頁可讀範圍時會提示縮短備註，不產生缺漏的圖片。

| 類型 | 填寫位置 | 租客可見 | 保存方式 |
| --- | --- | --- | --- |
| 固定備註 | 設定 → 各戶備註 | 是 | 新帳單保存存檔當時的文字 |
| 房東備註 | 設定 → 各戶備註 | 否 | 私用紀錄，但會包含在 CSV 備份中 |
| 當期備註 | 計算帳單 → 各戶存檔按鈕上方 | 是 | 僅屬於該張帳單 |

當期備註按樓層分開。未存檔的文字會記憶在此瀏覽器；成功存檔後清空該戶文字，變更帳單日期時清空兩戶文字，儲存失敗則保留。

修改設定不會改寫新帳單已保存的備註；舊帳單沒有固定備註快照時，報表沿用目前設定。

### 7. 歷史資料

可篩選全部或單一樓層，依日期由新到舊排列，並顯示篩選結果的筆數與應收合計。

- **卡片模式**：手機單欄、桌面雙欄，顯示總額與各項費用。
- **表格模式**：各項費用並列，方便跨期比較；窄螢幕可左右滑動。
- 兩種模式都可展開「用電、計算與備註」，查看台電區間、實際抄表日期、讀數、分攤依據與帳單備註。
- 點「查看／複製報表」顯示 LINE 報表，再點「複製報表」。
- 可逐筆刪除或清空所有帳單。清空不受樓層篩選限制，獨立抄表紀錄會保留。

### 8. 水電費儲值

儲值獨立於租金。各戶可在「設定 → 各戶基本資料」以「啟用儲值功能」開關個別控制，例如關閉 5 樓、保留 6 樓。

**登記儲值**：在「房客儲值 → 登記儲值」選擇樓層與實際收款日期，輸入金額後按「登記水電費儲值」。各樓層分開保存紀錄、備註與餘額。

**抵扣費用**：可在「計算帳單」的樓層卡片或「房客儲值 → 待抵扣費用」勾選項目。

- 預設勾選電費與水費，瓦斯費、管理費、雜費／其他需額外勾選；全不勾選即不扣款。
- 新帳單存檔時才實際扣款，勾選狀態會記憶；既有帳單每次操作時重新選擇。
- 餘額不足時，依電費、水費、瓦斯費、管理費、雜費／其他的順序抵扣已勾選項目，其餘費用照常應收。
- 補登舊日期帳單也按存檔當下的餘額扣款。

例如預付 3,000 元、本期水電 800 元，扣款後餘額為 2,200 元，租金照原額收取。

**先開帳單、後收儲值**：在「歷史資料」對該筆帳單按「選擇抵扣項目」，確認費用尚未另行收款後套用。系統只抵扣勾選項目尚未抵扣的部分，餘額不足時可在下次儲值後繼續；不會新增帳單或改動原本費用。

**更正與返還**：

- 刪除帳單會返還抵扣。
- 清空帳單會返還全部抵扣，並保留儲值紀錄。
- 誤登儲值可在「儲值與抵扣明細」刪除，但不能使餘額小於零；已使用的儲值須先刪除相關帳單。

**明細**：可按樓層及「儲值／費用抵扣」篩選，儲值顯示正額、抵扣顯示負額。抵扣依帳單日期排序，每張帳單顯示累計抵扣，並非逐次扣款的時間紀錄。餘額卡片顯示所有已啟用樓層的總額。

**停用樓層**：按「儲存房客設定」後生效。停用後不新增儲值、不抵扣新舊帳單，並從計算頁與房客儲值頁隱藏；既有餘額與紀錄會保留，重新開啟後恢復。全部停用時會顯示前往設定的提示。

## 電費分攤演算法

本工具採用「累進理論費用 + 差額分攤」，費率常數位於 [`js/data.js`](./js/data.js)：

```text
1. 分別計算 5F、6F 若獨立計費的理論電費（C5理、C6理）
2. 累進差額 ΔC = 台電帳單 − (C5理 + C6理)
3. 各戶分攤差額 = ΔC × (本戶度數 / 總度數)
4. 各戶應付 = 理論電費 + 分攤差額
5. 確保 5F + 6F = 台電帳單（四捨五入誤差由 6F 吸收）
```

兩戶電費合計會等於輸入的台電帳單金額，但各戶平均單價可能不同。

> [!WARNING]
> 本工具未自動驗證各戶單價上限，分攤結果不代表符合相關法規。台電金額、度數與抄表日期仍需由使用者自行核對。

## 資料與備份

帳務資料保存在目前執行環境的 localStorage，不會上傳到伺服器。

> [!CAUTION]
> 清除瀏覽器網站資料可能會刪除帳務內容，請定期匯出備份。CSV 備份含收款帳號、備註與房東私用備註，請妥善保管，不要提交到公開儲存庫。

### 備份與還原

1. 前往「設定 → 備份與還原」。
2. 點「備份／匯出 CSV」，下載所有樓層的帳單、房客設定、抄表紀錄與儲值資料，不受歷史樓層篩選影響。
3. 點「匯入資料」選取 CSV 或舊版 JSON，核對確認訊息後還原。

匯入會先驗證格式，確認後**覆蓋**現有帳單、儲值及備份內的房客設定，請先匯出目前資料。尚未存檔的輸入、顯示模式與主題偏好不在備份內。

- 編碼為 UTF-8（含 BOM），使用中文欄名；「資料類型」區分房客設定、逐筆帳單、抄表清單與抄表紀錄等資料。
- 銀行代號、帳號、帳單編號與可能被試算表解讀成公式的文字會加上單引號保護，匯入時自動還原。
- 以 Excel 編輯時，請將上述欄位保留為文字、維持完整欄名，並另存為 UTF-8 CSV。
- 「儲值功能啟用」欄保存 `true`／`false`。
- 「租客備註」欄保存固定備註，「當期備註」欄保存單張帳單文字，「其他費用內容」欄保存其他費用說明。
- 電費、水費、瓦斯費、管理費、雜費各有獨立的抵扣欄位。「水電儲值抵扣」為相容舊版的欄名，現在代表全部項目的抵扣總額。

</details>

<details>
<summary><strong>舊版備份相容性</strong></summary>

- 舊版 31／33／35 欄 CSV 與 JSON 仍可匯入。
- 匯入接受舊欄名「銀行代碼、帳戶名稱、銀行帳號」；匯出統一為「銀行代號、戶名、帳號」。
- 沒有銀行名稱、分行名稱或其他費用內容的舊備份仍可匯入，原有資料會保留。
- 沒有儲值開關設定的既有資料，預設為啟用。
- 未包含抄表清單的舊備份，會保留本機的獨立抄表資料。
- 沒有儲值資料的舊備份，匯入時會清空儲值，以免與還原的帳單重複計算。
- 舊備份只有水電合計抵扣時，會沿用總額並按電費優先、水費其次分配，不會重複扣款。
- 修改抄表不會回頭改寫已存檔帳單；清空帳單也不會清空獨立抄表紀錄。

</details>

<details>
<summary><strong>資料驗證 ID</strong></summary>

匯出 CSV 時，每筆資料都會附上「資料驗證ID」：SHA-256 雜湊的前 20 碼大寫十六進位字元。

**演算法**：將該列除驗證 ID 以外的「欄名、儲存格文字」配對，依欄名排序後轉為 JSON，再以 UTF-8 計算 SHA-256。

- 不影響結果：CSV 引號、檔案 BOM、列與列之間的換行、欄位順序。
- 影響結果：儲存格內的文字、數字格式、空白與換行。

**匯入行為**：含此欄位的 CSV 每列都必須驗證成功，空白或不符會中止匯入並指出資料筆次。因此直接編輯 CSV 內容會使驗證值失效，請在程式中更新帳務後重新匯出。沒有此欄位的舊 CSV 與 JSON 仍可匯入，下次匯出時會補上。

這是內容一致性檢查，並非身分認證或數位簽章，也不保證 ID 絕不重複，且不會偵測資料列遭刪除。

</details>

## 開發

本專案為純前端應用，使用 HTML、CSS 與原生 JavaScript，沒有建置步驟，也不需要安裝相依套件。

### 本機執行

PWA 必須透過 HTTPS 或 `localhost` 使用；直接雙擊 `index.html` 無法啟用離線功能。

```sh
git clone https://github.com/bruce-yang-422/landlord-billing-manager.git
cd landlord-billing-manager
python -m http.server 8080 --bind 127.0.0.1
```

開啟 <http://localhost:8080>。若要測試離線功能，請等待頁面顯示「已可離線使用」，在開發者工具切換為離線並重新整理，再確認計算、存檔與歷史紀錄仍可使用。

### 測試

需要 Node.js 22，測試涵蓋費用計算、抄表配對、CSV 相容性、備註、導覽與 PWA 快取：

```sh
node --test tests/*.test.cjs
```

### 發布

上傳完整專案，並遞增 [`service-worker.js`](./service-worker.js) 中 `CACHE_NAME` 的版本號。

- HTML、CSS、JS 採同版本預先快取，更新會等舊版視窗全部關閉後才啟用。
- 快取名稱包含部署路徑，避免同網域的其他部署互相刪除快取。
- 舊版 `v1`～`v3` 未包含部署路徑的快取會保留，避免刪除其他部署的資料。

## 已知限制

- 目前的分攤與畫面以 5F、6F 兩戶共用一個電號為前提。
- 不支援換表或讀數歸零，請勿填入比上期小的讀數。
- 資料不會跨裝置同步，需透過 CSV 匯出與匯入轉移。
- 抄表不會自動產生月租帳單；抄表紀錄不足時，系統也不會將單月用電視為兩個月。
